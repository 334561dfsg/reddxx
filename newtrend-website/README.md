# New Trends 独立前端

以 newtrendcapital.com 当前公开页面及已登录账户界面为参照，放在仓库根目录的独立 Vue 3 + Vite 项目。没有修改现有管理后台，不依赖后台路由或 Ant Design 管理界面样式。

## 运行

在仓库根目录执行一次 `npm run dev` 即可，原型总入口为 http://localhost:5173/ ，新站为 http://localhost:5173/NewQuantCapital/ 。无需单独启动 4173。

在仓库根目录执行 `npm run build` 同时构建所有原型，`npm run preview` 启动统一生产预览。新站仍以独立 HTML 页面加载，样式和路由不影响其他原型。服务器部署时，`/NewQuantCapital/*` 应回退到对应的 `index.html`。

## 数据与边界

这是可运行的前端演示，不连接原站 API。默认展示已登录界面；账户资料为虚构数据。所有 mock 业务数据只存在内存中（不写入浏览器存储），刷新即重置。

资金统一走 `src/mock/ledger.js` 的分账户、分币种账本：“真實”初始为空，“模擬”初始为 100,000 USDT / 100,000 USDC / 2 BTC / 30 ETH / 500 SOL。理财、量化基金、策略、交易、C2C、捐赠与兑换都通过账本扣款和入账，两种模式的记录互不影响。种子数据以页面加载时间为基准（`src/mock/clock.js`），到期、结算等生命周期按同一时钟推导。借贷使用根目录 dev server 的共享内存 mock（与管理后台共用），独立于账本。

行情基于采集时的快照；首页每 2.4 秒分批模拟价格变化，按上一笔价格触发红绿淡出提示，可暂停更新，后台标签页停止更新。首页合作伙伴标识连续循环滚动，支持悬停、键盘聚焦和按钮暂停；减少动态效果偏好下静态展示全部标识。K 线和盘口为确定性示意数据。演示账本仅用于本地演示，不用于实际交易结算。未采集到的成交量显示“—”。原站动态数字与本地快照会不同。

原站的图片、字体、图标及视频已放在 `public/assets`，资源来源映射见 `asset-sources.json`。展示的品牌、合作关系、收益率及监管声明属于来源网站内容，本项目不验证或背书这些声明。未复制登录凭据、私有账户信息、充值地址或真实证件。没有外部表单提交、钱包签名或真实客服发送。

新闻详情保留原站标题和摘要，并提供自行撰写的多语言简述与原文入口，未复制第三方完整正文。当前新闻快照为每语言 20 条，不包含全部历史。账户表单使用本地演示校验、状态与虚构资料，未接入邮件/短信、认证审核、商家服务或原站账户后端；专业图表工具仍为示意。法律文档语言沿用原站回退行为（部分语言显示英文）。

各页按原站独立限宽居中：新闻/资产 1400px，个人中心/帮助/法律 1280px，理财/量化/奖励 1440px，邀请 1080px，安全与认证表单 768px；本网站不使用管理后台的全屏布局约束。

## 代码结构

- `src/routes.js`：命名路由表（无 DOM 依赖，供测试解析）；`src/main.js` 只负责创建应用。
- `src/mock/`：时钟、ID、价格快照、账本与目录事实（`catalog.js`）；各业务 store（`earnPortfolio.js`、`quantFundPortfolio.js`、`strategyPortfolio.js`、`tradingFunds.js`、`c2cStore.js`、`walletRecords.js`）只通过账本改动资金。
- `src/components/ui/`、`src/utils/format.js`、`src/utils/coinAssets.js`：共享组件与格式化；`src/components/overlay/` 为弹窗内容，`Overlay.vue` 只做外壳；`src/pages/account/` 为个人中心子页。
- `src/platform/`：引用仓库根目录共享模块（反馈 toast、借贷规则与客户端）的唯一入口。
- `src/styles/index.css`：全局样式入口；`tokens.css` 是唯一的 `--nt-*` 定义处；领域样式由各页面引入。
- 约定与历次决定记录在 `AGENTS.md`，重构说明见 `docs/designs/2026-11-26-frontend-review-and-refactor.md`。

## 测试与检查

在本目录执行：

- `npm test`：单元测试（路由表、账本与生命周期、种子有效性、申购资格、模式隔离、各业务规则）。
- `npm run test:sites`、`npm run check:locales`、`npm run build`。
- `npm run css:dead`、`npm run css:overridden`：报告无引用的选择器与被同选择器覆盖的声明（加 `--write` 应用，应用后需目视确认）。
- 根目录 `npm run check:feedback`：反馈必须使用 toast。

`design-qa.md` 与 `qa/` 保存早期的视觉对照记录与截图。浏览器检查在桌面宽度进行，不代表 Safari 或真机验收。

## 语言包维护

界面文案统一使用 `src/locales/<语言>/<模块>.json` 和固定翻译键，例如 `profile.changePassword.title`。六种语言的键和插值参数保持一致；默认回退英文。新闻和法律正文独立存放于 `src/content/`。旧的中文原文匹配、别名表和补充翻译表已删除。

新增文案时同步补齐六套语言包，然后在根目录运行 `npm run check:locales --prefix newtrend-website`。调用示例与状态保持规则见 [语言包说明](src/locales/README.md)。

站内 URL 不携带语言段；语言切换保留当前 URL，并通过本地偏好保存。旧的带语言链接自动跳转到对应新地址。
