# 全站视觉检查（2026-11-24）

## 检查方法

通过浏览器读取渲染后的字号、行高、容器、卡片内边距、圆角和文档宽度，同时抽查截图。使用桌面 1440×900 与窄屏 390×844（部分账户说明页 390×900）。窄屏模拟不等同于真实触屏或虚拟键盘测试。

## 页面覆盖

首页、C2C 买入、Earn 产品/收益/借贷、AI 量化首页/基金、资产首页/记录/划转、账户首页/邀请/活动/帮助/邮箱绑定、登录/注册/找回密码、登录密码/资金密码/2FA/设备/认证/联名账户、资讯、公益、关于、隐私、用户协议、风险说明、监管说明，以及永续/交割/现货。

共检查 36 个 URL；其中 assets/deposit、assets/withdraw、assets/convert 在现有原型中均展示 Fund Records，不能视为三个独立业务页面的验证。

## 结果与本轮修正

- 被检查 URL 在上述视口均无文档级横向溢出；不代表所有内部控件均已逐项验证。
- 常规页面标题为桌面 32px、窄屏 26px；普通卡片内边距为 24px/16px。
- 首页行情条的小字从 11px 补齐到 12px。
- 交易盘口单位、记录单位、行情摘要及相关辅助文字从 10–11px 补齐到 12px。
- 公益页标题纳入统一页面标题尺度。
- C2C 报价卡内边距纳入卡片 token。
- 补测德语 Earn 窄屏：导航可换行，文字保持可读，无文档级横向溢出。已恢复检查前英语及默认视口。
- 既有三档圆角、主体字体和主色沿用统一规范；没有将正负涨跌色、警告色或焦点状态强行合并。

## 有意保留的差异

首页营销主标题 72px/36px；文章阅读正文 16px；交易终端以 12px 数据、14px 控件为主；关键数值与代码使用等宽数字/字体。头像、图标、胶囊按钮、图表标记不按普通文本/面板规则缩放。
