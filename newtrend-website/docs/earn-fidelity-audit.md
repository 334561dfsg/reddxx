# 理财页面复刻核验 — 2026-11-25

范围：`/NewQuantCapital/earn/simple`、八款产品详情、申购弹窗。参考：<https://newtrendcapital.com/zh-TW/earn/simple>。

## 已核对和实现

- 在浏览器中逐个读取八款产品详情：产品名称、日利率、展示年化、期限、起投、最高申购、个人限额、已申购量、剩余额度、风险说明。
- 列表：1440px 居中外框、图标导航、持仓摘要、三个热门卡片、全部/活期/定期、总申购列、年化辅助行、页尾两行说明。保留用户先前移除日利率排序的决定；期限和起投使用原站表头排序，窄屏也可操作。
- 详情：960px 内容区域、产品摘要、热门标签、水平资金时间线、规则/额度双栏、实际申购占比、独立风险说明和底部申购条。
- 弹窗：512px 上限、产品摘要、最大/可用余额、按规则校验、余额不足充值入口、竖向时间线、活期/定期差异、预估收益、固定头尾、单一原生 modal owner。
- 使用源码已有的本地币种资源，没有引入新远程图片或额外依赖。NewQuantCapital 品牌和其他页面共享设计规范保留。
- APY 是参考页独立展示值，不能用四舍五入后的日利率乘 365 代替（例如 90 天产品 8.49%，而非 8.47%）。

## 浏览器实测

桌面 1920×929、平板宽度 1024×768、窄屏 390×844、横屏低高度 844×390。

- 产品详情进入/返回；全部、活期、定期各 8/4/4 项。
- 窄屏字段保留、无页面横向溢出；切换视口保留筛选。
- 定期与活期申购摘要/时间线；金额 1000 触发真实模式零余额错误和充值入口；最大金额为零时提示无效金额。
- 弹窗打开时聚焦金额；Tab/Shift+Tab 首尾循环；遮罩点击不关闭。
- 空草稿 Escape 关闭；已有草稿 Escape 保持打开并说明 intentional close 路径；取消/关闭后焦点返回申购按钮且 body scroll lock 清理。
- 打开弹窗从桌面切到窄屏再切横屏，保留输入金额且仅有一个打开实例；低高度仅 body 滚动，顶部关闭与底部操作保留在可见视口。
- 重开清除金额、错误、成功状态。
- 本地模拟模式：1000 USDT 活期预估 0.123 USDT，提交显示成功、确认按钮移除、防止重复提交；我的理财出现一条审核中记录。
- 检查期间浏览器控制台未报告 error。
