# NewQuantCapital UI 规范

适用范围：newtrend 公共站点。管理台和交易 V2 不受影响。
实现入口：`styles/site-containers.css`、`styles/site-design-system.css`；圆角变量位于 `styles.css`。

| 项目 | 桌面 | 窄屏（小于 768px） |
| --- | --- | --- |
| 页面容器 | 最大 1400px，居中 | 100% |
| 左右内边距 | 24px | 16px |
| 页面顶部留白 | 32px | 24px |
| 内容区块间距 | 32px | 24px |
| 网格间距 | 24px | 16px |
| 卡片内边距 | 24px | 16px |
| 页面标题 | 32px / 1.3，600 | 26px / 1.3，600 |
| 区块标题 | 24px / 1.3，600 | 20px / 1.3，600 |
| 卡片标题 | 16px / 1.5，600 | 同桌面 |
| 正文和控件 | 14px / 1.6 | 同桌面 |
| 辅助文字 | 12px / 1.5 | 同桌面 |
| 关键数值 | 28px / 1.3，600，等宽数字 | 同桌面 |
| 控件最小高度 | 40px | 粗指针 44px |

间距以 4/8/12/16/24/32/48px 为统一尺度。卡片/弹窗/菜单圆角 12px，输入控件/菜单项 8px，小标签 4px。圆形图标与胶囊按钮按语义保留。

正文、辅助信息通过颜色和字号区分；避免通过大量不同字号表达同一级信息。页面级标题不写内联字号。新增页面复用 page-wrap、page-title、page-desc、card、section-gap、form-stack 等公共类。

## 密度与例外

- 交易终端使用现有紧凑布局，共享圆角和配色；不套用营销页的大标题或卡片内边距。
- 首页主视觉标题、文章正文、认证双栏布局保留其阅读层级；普通区块和容器仍统一。
- 填写类账户表单最大 768px；头像、图标、图表尺寸不当作页面宽度。
- 表格容器保留零内边距，行内结构自行管理；不能通过统一 card padding 破坏表格边界。
- 安全区、键盘焦点、滚动区域、窄屏核心功能不能因视觉规范被隐藏。

## 验证

本轮检查桌面公共页面标题、卡片、表单和区块间距及构建。移动端、200% 缩放、长翻译、虚拟键盘和完整键盘流程须另做回归，不能据桌面检查推断通过。

## 控件字号补充

顶部导航、个人下拉菜单、筛选按钮、表单标签、普通表格数据统一 14px；菜单副标题、表头、提示、状态说明统一 12px。弹窗标题、资料卡片标题统一 16px。资讯列表标题 18px，文章正文仍按阅读需要保留 16px。交易数字/标签维持紧凑的 12px，交易操作和输入值 14px。图标、表情、品牌标记不按文字字号缩放。

对全局弹窗和传送到根节点的控件单独应用规范，不依赖 main 容器继承。检查字号时读取实际 computed style，不能只检查公共变量定义。
