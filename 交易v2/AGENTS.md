# 交易 V2 约定

这是共用根项目服务的公共交易前端子目录，保持当前暗色风格和已有共享交易组件。不要将后台管理 UI 的 Ant Design 外观迁移到此公共交易站。

- 用户最新决定（2026-11-24）：仅作为根项目二级文件夹，与其他入口共用根 Vite 服务、依赖、构建和部署；不得单独起服务。页面源码及资源保留在本目录。
- 用户决定（2026-11-24）：导航允许外观占位，非交易入口不与原项目关联，不跳转原站。
- 合约、期权、现货三个模式、当前及历史七类记录继续保留。
- 不恢复技术指标入口、参数弹窗或均线，只保留 K 线与成交量。
- 加密交易对和计价使用 USDT；卖出现货的基础资产数量及外汇标识保持原语义。
- 不恢复跟单、历史记录筛选条或下单表单资金快捷入口。
- 下单按钮保持固定在面板底部，字段区域单独滚动，输入框与自定义下拉框保持统一尺寸。
- 页面不展示本地演示、模拟行情、不连接真实交易等说明文案，技术限制写在文档中。
- 保留六语言模块包与固定翻译 key；修改翻译后运行 npm run check:locales。
- 保留共享弹窗所有权、固定头尾、内容滚动、背景点击不关闭、焦点管理和 reduced-motion 等交互约定；遵守根 AGENTS.md 的适用约束。
- 使用根目录 npm run dev / build / preview；本目录的同名命令只转发至根项目。测试使用 npm test --prefix 交易v2 和 npm run check:locales --prefix 交易v2。
- 主动启动本地预览并进行适用验证，如实报告未完成的设备和交互检查。

- 用户决定（2026-11-24）：URL 使用 `/trade-v2/` 子路径，不携带 zh-TW 等语言段；语言切换不得改变 URL 或重建交易页面。

- 用户决定（2026-11-24）：三个交易模式均显示顶部收藏星标，与列表收藏状态同步；收藏按本项目 localStorage 键保存，刷新和切换模式后保留。
