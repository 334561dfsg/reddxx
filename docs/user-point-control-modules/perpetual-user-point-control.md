## 1. 操作

- 在“永续管理／用户点控”中，管理员可为单个用户设置控盘类型和控盘方式；规则默认长期生效，不填写具体金额、价格或收益率。
- 控盘方式支持：盈利、做高盈利、做低盈利、亏损、做高亏损、做低亏损。
- 同一用户在永续模块同一时刻只有一条当前用户点控规则；模块点控与用户点控设置仅表示来源，最后一次成功设置替换当前规则，被覆盖规则不恢复。
- 模块点控、修改或取消只影响永续模块；用户管理点控设置以同一批次更新交割、永续、现货三个交易模块。修改产生新规则并将旧规则置为“已覆盖”，取消只取消当前规则。

## 2. 触发

- 仅在目标用户的持仓最终平仓并完成结算时，按当前有效规则分别判断。
- 同一用户有多个持仓时，各持仓的最终平仓结算分别判断；未平仓持仓和实时浮盈亏不触发。
- 不以插线方式修改 K 线、标记价格或实时浮盈亏，不修改公共行情或其他用户结果。

## 3. 规则

- 点控只约束目标用户最终为盈利或亏损，具体金额由仓位、开平仓价格、杠杆、保证金、手续费和资金费按永续产品规则计算，并以扣除费用后的已实现净结果判断。
- 做高盈利、做低盈利、做高亏损、做低亏损只表示最终盈亏幅度，具体金额由永续模块按自身高/低幅度规则计算。
- 已实现净结果 `> 0` 为盈利、`< 0` 为亏损、`= 0` 既非盈利也非亏损；零值执行失败。缺少仓位、价格、杠杆、保证金或费用等必要计算依据时同样执行失败。
- 新增或修改的点控规则长期生效，对后续每次符合条件的最终平仓结算均生效，直到被取消或被新规则覆盖。
- 历史一次性规则只有本次实际选中并成功用于最终平仓结算结果时才消耗执行机会；被更高优先级规则挡住则不消耗。
- 结果优先级固定为：单笔订单或持仓控制 > 当前有效用户点控 > 模块全局场控 > 自然结果。

## 4. 状态

- 新增或修改的长期规则设置后为“生效中”；一次成功结算后仍为“生效中”。
- 历史一次性规则设置后为“待执行”；被选中并成功用于最终平仓结算后为“已执行”；结算失败、零值、计算依据缺失或被更高优先级规则挡住时仍为“待执行”。
- 新设置替换时旧规则为“已覆盖”，取消时当前规则为“已取消”；两种情况均不恢复更早规则。
- 一次设置、修改或取消各记一条操作日志，记录来源、影响范围、变更前后、操作人、时间、备注和批次号；覆盖是该条日志中的变更结果，不另记操作日志。
- 每个业务结果执行记一条执行日志，记录业务单号、执行前后结果及成功或失败。

## 5. 验收点

- 管理员只能设置控盘类型和控盘方式，不能填写控制周期、金额、价格或收益率；新规则默认长期生效。
- 模块点控永续规则后，其他模块的规则和状态不变。
- 用户点控设置会替换永续当前规则；之后成功的永续点控可再替换它，取消后均不恢复已覆盖规则。
- 同一用户的多个持仓仅在各自最终平仓并结算时分别判断；未平仓、实时浮盈亏、K 线和标记价格变化不触发。
- 新规则保存后默认“生效中”，后续符合条件的最终平仓结算持续判断，直到取消或覆盖。
- 扣费后已实现净结果 `> 0` 判为盈利、`< 0` 判为亏损；`= 0` 执行失败。
- 缺少仓位、价格、杠杆、保证金或费用等必要计算依据时执行失败，并有失败执行日志。
- 最终金额按永续产品规则计算，不插线且不修改公共行情或其他用户结果。
- 一次设置、修改或取消各有一条字段完整的操作日志，每个业务结果执行有一条包含业务单号、前后结果和成败的执行日志。
