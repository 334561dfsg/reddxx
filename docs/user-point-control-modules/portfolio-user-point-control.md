## 1. 操作

- 在“投资组合／用户点控”中，管理员可为单个用户设置控盘类型、控盘方式和控制周期；不填写具体收益率或收益金额。
- 控盘方式沿用交易侧术语展示；投资组合按产品规则映射为高收益、默认收益、低收益或最低收益。
- 同一用户在投资组合模块同一时刻只有一条当前用户点控规则；模块点控与用户点控设置仅表示来源，最后一次成功设置替换当前规则，被覆盖规则不恢复。
- 模块点控、修改或取消只影响投资组合模块；用户点控设置以同一批次更新六个模块。修改产生新规则并将旧规则置为“已覆盖”，取消只取消当前规则。

## 2. 触发

- 仅在实际收益成功入账、到期结算成功或赎回结算成功时，按当前有效规则判断。
- 同一业务收益结果以首个成功完成的入账或结算事件为唯一执行；后续阶段和重复通知不重复执行。不同周期收益与赎回收益若分别形成独立业务结果，可各执行一次。
- 申购、持有期估值变化和失败赎回均不触发，也不消耗一次性控制规则；估值或预估收益只用于展示，不代表实际结果或已执行点控。

## 3. 规则

- 点控只约束目标用户进入对应收益档位；具体收益率和收益金额由投资组合模块按订单所属产品的收益区间、净值、份额和周期计算，不得突破产品收益与本金边界。亏损类控盘方式默认映射为低收益或最低收益，不默认扣本金；产品缺少对应收益区间时执行失败，一次性控制规则不消耗。
- 只有本次实际选中并成功用于业务收益结果的规则才消耗一次性控制机会；自然结果原本符合目标档位但该规则被选中参与成功入账或结算，仍为成功执行并消耗；被更高优先级规则挡住则不消耗。
- 永久控制规则对后续每个独立业务收益结果均生效，直到被取消或被新规则覆盖；同一结果的后续阶段或重复通知不再次执行。
- 结果优先级固定为：单笔订单或持仓控制 > 当前有效用户点控 > 模块全局场控 > 自然结果。

## 4. 状态

- 一次性控制规则设置后为“待执行”；被选中并成功用于首个有效入账或结算事件后为“已执行”；失败或被更高优先级规则挡住时仍为“待执行”。
- 永久控制规则设置后为“生效中”；单个独立业务收益结果执行成功后仍为“生效中”。
- 新设置替换时旧规则为“已覆盖”，取消时当前规则为“已取消”；两种情况均不恢复更早规则。
- 一次设置、修改或取消各记一条操作日志，记录来源、影响范围、变更前后、操作人、时间、备注和批次号；覆盖是该条日志中的变更结果，不另记操作日志。
- 每个业务结果执行记一条执行日志，记录业务单号、执行前后结果及成功或失败。

## 5. 验收点

- 管理员只能设置控盘类型、控盘方式和控制周期，不能填写具体收益率或收益金额。
- 模块点控投资组合规则后，其他五个模块的规则和状态不变。
- 用户点控设置会替换投资组合当前规则；之后成功的模块点控可再替换它，取消后均不恢复已覆盖规则。
- 同一业务收益结果的入账、到期结算与赎回结算均成功时只在首个成功事件执行一次，后续阶段及重复通知不再次执行永久控制或一次性控制规则。
- 不同周期收益与赎回收益分别形成独立业务结果时，各自可执行一次；单纯阶段变化不算新结果。
- 申购、持有期估值变化、预估收益和失败赎回均不触发；执行失败后一次性控制规则仍为“待执行”且有失败执行日志。
- 当前用户点控被选中并成功用于收益结果时，即使自然结果已符合目标档位也消耗一次性控制机会；被单笔订单或持仓控制挡住时不消耗。
- 具体收益由投资组合模块按净值、份额和周期计算，属于产品允许收益档位，且不突破产品收益与本金边界。
- 一次设置、修改或取消各有一条字段完整的操作日志，每个业务结果执行有一条包含业务单号、前后结果和成败的执行日志。
