## 1. 操作

- 在“投资组合／用户点控”中，管理员可为单个用户设置高收益或低收益，以及一次性或永久生效方式；不填写具体收益率或收益金额。
- 模块独立设置、修改或取消只影响投资组合模块；用户管理的统一点控会覆盖包括投资组合在内六个模块的当前规则。
- 修改时以新规则替换当前规则；取消只取消当前有效规则。

## 2. 触发

- 仅在实际收益成功入账、到期结算成功或赎回结算成功时，按当前有效规则判断。
- 申购、持有期估值变化和失败赎回均不触发，也不消耗一次性规则。
- 持有期估值或预估收益只用于展示，不代表实际结果或已执行点控。

## 3. 规则

- 点控只约束目标用户进入高收益或低收益档位；具体收益率和收益金额由投资组合模块根据净值、份额、周期和产品边界计算，不得突破产品收益与本金边界。
- 一次性规则只在一次符合条件的实际收益成功入账、到期结算成功或赎回结算成功后生效并结束；失败不消费规则。
- 永久规则对后续每次符合条件的实际收益入账、到期结算或赎回结算成功持续生效，直到被取消或被新规则覆盖。
- 结果优先级固定为：单笔订单或持仓控制 > 当前模块用户点控 > 用户管理统一点控 > 模块全局场控 > 自然结果。

## 4. 状态

- 一次性规则设置后为“待执行”；符合条件的实际收益入账、到期结算或赎回结算成功后为“已执行”；失败仍为“待执行”。
- 永久规则设置后为“生效中”；单次成功入账或结算后仍为“生效中”。
- 修改时旧规则为“已覆盖”，取消时当前有效规则为“已取消”。
- 设置、修改、覆盖、取消、执行成功和执行失败均保留日志。

## 5. 验收点

- 管理员只能设置高收益／低收益和一次性／永久，不能填写具体收益率或收益金额。
- 模块独立设置投资组合规则后，其他五个模块的规则和状态不变。
- 用户管理统一设置后，投资组合当前规则被覆盖并与其余五个模块一并更新。
- 实际收益成功入账、到期结算成功或赎回结算成功后，投资组合一次性规则才变为“已执行”。
- 申购、持有期估值变化、预估收益和失败赎回均不触发或消耗一次性规则。
- 失败赎回后，投资组合一次性规则仍为“待执行”且有失败日志。
- 具体收益由投资组合模块按净值、份额和周期计算，属于产品允许收益档位，且不突破产品收益与本金边界。
