## 1. 操作

- 在“现货管理／用户点控”中，管理员可为单个用户设置盈利或亏损，以及一次性或永久生效方式；不填写具体金额、价格或收益率。
- 模块独立设置、修改或取消只影响现货模块；用户管理的统一点控会覆盖包括现货在内六个模块的当前规则。
- 修改时以新规则替换当前规则；取消只取消当前有效规则。

## 2. 触发

- 仅在卖出或其他业务事件形成可确认的已实现净盈亏，并成功入账时，按当前有效规则判断。
- 持仓市值变化、未卖出资产的浮动盈亏、未形成已实现净盈亏的成交和入账失败均不触发，也不消耗一次性规则。
- 用户点控不修改公共行情、成交行情或其他用户结果。

## 3. 规则

- 点控只约束目标用户最终为盈利或亏损，具体金额由成交、成本和手续费按现货产品规则计算，并以扣除费用后的已实现净结果判断。
- 一次性规则只在一笔符合条件的已实现净盈亏成功入账后生效并结束；失败不消费规则。
- 永久规则对后续每次符合条件的已实现净盈亏成功入账持续生效，直到被取消或被新规则覆盖。
- 结果优先级固定为：单笔订单或持仓控制 > 当前模块用户点控 > 用户管理统一点控 > 模块全局场控 > 自然结果。

## 4. 状态

- 一次性规则设置后为“待执行”；已实现净盈亏成功入账后为“已执行”；结算或入账失败仍为“待执行”。
- 永久规则设置后为“生效中”；单次成功入账后仍为“生效中”。
- 修改时旧规则为“已覆盖”，取消时当前有效规则为“已取消”。
- 设置、修改、覆盖、取消、执行成功和执行失败均保留日志。

## 5. 验收点

- 管理员只能设置盈利／亏损和一次性／永久，不能填写金额、价格或收益率。
- 模块独立设置现货规则后，其他五个模块的规则和状态不变。
- 卖出或其他业务事件形成已实现净盈亏并成功入账时，才可触发现货规则。
- 持仓市值和未卖出资产的浮动盈亏不触发或消耗一次性规则。
- 入账失败后，现货一次性规则仍为“待执行”且有失败日志。
- 结果按费用后的已实现净结果判断，不修改公共行情、成交行情或其他用户结果。
- 单笔订单或持仓控制存在时，其结果优先于现货用户点控。
