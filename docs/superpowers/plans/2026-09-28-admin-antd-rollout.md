# 管理后台 Ant Design Vue 全模块迁移计划

## 目标与范围

用户已确认迁移全部管理后台，其他端暂不改。沿用 Vue 3、Ant Design Vue 4；保留现有业务数据、权限、验证、确认等级与异步反馈。桌面优先；沿用已确认的紧凑菜单、彩色 32px 行按钮、右侧固定操作列和即时列设置。

## 实施分工

- [x] 交易与产品页面：aiQuant、contracts、delivery、lending、liquidity、perpetual、portfolio、spot。
- [x] 运营与系统页面：agent、assets、customer-service、platform、system、user、user-control；保留已确认的用户列表和充值报表设计。
- [x] 业务公共组件：按钮、输入、选择、分页及业务弹窗内部控件；保持 props、emits、原生 DOM ref 与已有生命周期契约。
- [x] 全局集成：Header 通知/账号浮层、组件注册、旧样式隔离、测试适配及浏览器检查。

## 具体约束

1. 不改变代理端/用户前台；共享到其他端的组件必须保留原表现或显式提供仅管理后台生效的实现。
2. 控件替换不是 CSS 改名：使用真实 Ant 控件，输入使用正确 value/checked 事件，提交与查询语义不变。
3. 原生 DOM ref 的 focus/contains/校验路径不能被组件实例替代。
4. 表格保留全部字段、行操作、排序、分页和记录标识；复杂表格不可静默删除或丢弃 slot 内容。
5. 业务弹窗不得引入两套焦点锁、遮罩或滚动锁；不能为了视觉统一破坏已有风险确认和请求隔离。
6. 禁止提交、推送或部署，直到用户另行要求。

## 验证步骤

- 逐模块编译所有 SFC，检查未注册组件、重复属性与剩余原生控件。
- 执行 `node --no-experimental-global-navigator --test`；源码结构测试可适配组件结构，业务与时序断言不得删除。
- 执行 `npm run build` 和 `git diff --check`。
- 在真实浏览器覆盖代表性模块的查询、分页、弹窗、关闭和错误状态；检查旧样式污染、重复边框和按钮 ref。
- 明确记录保留的自定义业务布局/生命周期及没有实际验证的流程，不把构建通过等同于全量人工回归。

## 实施结果与验证记录

- 修改94个管理后台页面、51个后台组件文件；新增局部Ant适配器，保持原有模型值、事件和DOM焦点引用。
- 迁移管理后台表格、表单控件、分页、开关及56个普通Modal/Drawer实例；页头使用Ant Popover、Badge、Avatar、Switch和Breadcrumb。
- 代理端、财务端、用户前台无直接文件改动。跨端复用的审核组件保留agent分支；SelectOnlyCombobox继续保留共享实现。
- 复杂业务弹窗保留useDialogLifecycle等已有层级/确认/MFA管理，内部控件使用Ant；文件上传输入、富文本编辑器、原生form提交继续保留浏览器契约。并非所有业务容器都改为Ant Modal/Drawer。
- 修复交叉评审发现的开关click事件参数、Checkbox半选属性，以及三个双栏表单误置于Modal标题slot的问题。
