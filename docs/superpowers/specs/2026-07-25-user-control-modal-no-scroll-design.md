# 用户点控弹窗无滚动紧凑设计

## 目标

压缩用户点控弹窗的纵向高度，使其在常见 768px 及以上桌面视口中完整显示，不出现弹窗内部滚动条，同时保留现有设置内容和交互。

## 布局调整

- 弹窗宽度由 `max-w-xl` 调整为约 680px，使用横向空间降低纵向堆叠。
- 移除弹窗容器的 `overflow-y-auto`。
- 标题区、正文区和底部操作区均缩小上下内边距。
- “现有规则”和全局覆盖警告合并为一块紧凑信息区。
- 控制方向卡片同时呈现对应的交易和理财效果，删除重复的独立效果卡片。
- 控制方向与生效方式卡片使用更小内边距和文本间距。
- 影响模块标签缩小尺寸与间距。
- 操作备注文本框由三行改为两行。

## 响应式约束

- 常见桌面视口不显示弹窗内部滚动条。
- 弹窗仍保留视口边缘留白。
- 极小高度视口允许外层页面自然滚动，避免内容被裁切；不恢复弹窗内部滚动区域。

## 范围

只修改 `UserControlModal.vue` 的布局和样式，不修改表单字段、校验、提交逻辑、MFA 流程或点控业务规则。

## 验收

- 弹窗源码不包含 `overflow-y-auto`。
- 独立的“交易类效果 / 理财类效果”结果卡不再渲染。
- 备注框使用两行。
- 所有原有字段、提示、取消和确认操作仍可使用。
