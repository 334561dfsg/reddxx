# 用户裂变与代理操作设计

## 目标

将用户操作中的裂变关系与代理业务明确分组，补充用户级代理报表，并为关系类长列表提供一致分页，避免不同业务口径混排或列表无限增长。

## 操作入口分组

原“用户与关系”拆为以下三个连续分组：

1. 用户资料
   - 编辑资料
2. 裂变关系
   - 查看直属裂变下级
   - 查看全部裂变下级
   - 重设裂变上级
   - 查看裂变团队报表
3. 代理管理
   - 设置为代理；当前用户已经是代理时显示取消代理身份
   - 查看代理报表，仅代理用户显示

每组内部保持桌面两列、窄屏一列的紧凑卡片布局。裂变关系与代理管理不使用额外 Tab，所有可用入口保持一次点击可达。资金、会员和风控分组顺序与行为不变。

入口名称、说明、Drawer/Dialog 标题、字段名称、搜索说明、确认文案与空状态统一使用“裂变上级”“裂变下级”“裂变团队报表”或“代理”术语，不继续使用含义不明的单独“上级”“下级”“团队报表”。

## 裂变功能

直属和全部裂变下级继续读取用户父子关系。裂变团队报表继续按全部后代汇总人数、活跃人数、代理人数、余额、交易量和盈亏，并按直属裂变分支展示明细；不将其解释为代理佣金报表。

重设裂变上级保留现有候选排除、确认、错误、焦点和提交逻辑，仅统一业务文案。

## 用户级代理报表

新增独立右侧 Drawer，仅从代理用户的“查看代理报表”入口打开。普通用户不显示该入口，避免打开无意义的空报表。

报表由用户 ID 获取独立、确定性的代理数据，包含：

- 概览：直属客户数、活跃客户数、累计业务量、累计佣金。
- 产品线汇总：各启用产品线的业务量、佣金和订单数。
- 代理业绩明细：按日期倒序展示业务量、活跃客户、新增客户、订单数和佣金。

代理报表只表达一级代理名下客户和代理佣金，不递归统计裂变后代。演示仓储接口按用户 ID 返回隔离副本，后续可直接替换为后端接口。

Drawer 复用共享层级与生命周期：视口固定遮罩、遮罩不可关闭、固定标题与关闭按钮、单一内容滚动区、200/150ms 动画、Reduced Motion、背景隔离、焦点约束与返回。

## 分页

以下四个列表统一使用每页 10 条：

- 直属裂变下级。
- 全部裂变下级。
- 裂变团队报表分支明细。
- 代理报表按日业绩明细。

分页规则：

- 显示总条数、当前页、总页数、上一页、有限页码和下一页。
- 搜索或筛选条件变化时回到第一页。
- 数据量变化导致当前页越界时，自动收敛到最后一个有效页。
- 切换用户、列表模式或重新打开 Drawer 时重置到第一页。
- 候选卡片或明细只渲染当前页；总数与筛选结果数使用完整数据计算。
- 分页控件位于列表之后，不新增内部滚动容器；仍由 Drawer 唯一内容区滚动。
- 不足两页时隐藏页码操作，但保留必要的结果计数。

## 状态与错误

- 裂变列表过滤后为空时区分“没有关系数据”和“筛选无结果”。
- 代理报表数据为空时分别表达“暂无产品线汇总”和“暂无代理业绩明细”。
- 选择列表成员后翻页，不保留一个当前页不可见的高亮选择；筛选或翻页会清除该展示态。
- 代理报表读取失败时保持 Drawer 打开，显示可聚焦文本错误，不自动关闭。

## 验证

- 配置测试证明分组、上下文入口和名称正确。
- 组件测试覆盖四个列表的分页、过滤重置、越界收敛和用户切换重置。
- 仓储测试覆盖代理数据按用户隔离、汇总字段与返回副本。
- Drawer 测试覆盖遮罩抵抗、固定框架、焦点、关闭顺序、动画、Reduced Motion 和多层返回。
- 运行全量测试、生产构建及差异检查；真实浏览器中未实际覆盖的视口、触摸、虚拟键盘和缩放检查必须在交付说明中明确列出。
