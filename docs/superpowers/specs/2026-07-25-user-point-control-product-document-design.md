# 用户点控通用版产品文档设计

## 目标

将已确认的用户点控界面和业务规则整理为一份可直接复制使用的通用版产品需求文档，使客户能理解功能范围和操作方式，开发与测试也能据此实现和验收。

## 文档结构

采用“产品正文＋开发测试附录”的单文档结构：

- 产品正文覆盖背景、目标、范围、名词、入口、页面、交互、状态、六模块规则、日志、异常和验收标准。
- 开发测试附录只保留实现一致性所需的批次、原子性、幂等、日志追溯和原型边界。
- 不在正文中使用代码字段或依赖具体前端 Mock 实现。

## 内容原则

1. 六个模块均纳入用户点控：交割、永续、现货、AI量化、流动性挖矿和投资组合。
2. 用户点控设置覆盖六模块，模块菜单点控只影响当前模块。
3. 点控只设置方向和生效方式，具体结果由各模块计算。
4. 当前状态只使用未设置、待执行、生效中；结束结果在历史或日志中展示。
5. 用户点控设置任一模块失败时整体回滚。
6. 用户点控日志集中承载操作和执行记录，并支持分页。
7. 永续点控不修改公共行情，只约束目标用户最终平仓结算方向。

## 交付物

正式产品文档保存为 `docs/user-point-control-product-requirements.md`，可作为客户确认、产品归档、开发说明和测试验收的共同基线。
