# 用户列表点控快捷入口设计

## 目标

将用户管理列表“操作”下拉菜单中的“点控”和“取消点控”调整为两个始终同时展示、始终可以点击的快捷入口，使管理员无需根据列表状态寻找入口，并能集中处理从各业务模块单独设置的用户点控规则。

## 操作菜单

每个用户的操作下拉菜单固定包含：

- 点控
- 取消点控
- 点控日志

“点控”和“取消点控”不再根据“是否点控中”状态互斥展示，也不置灰。

## 点控快捷入口

点击“点控”始终打开用户点控设置弹窗：

- 若该用户没有有效规则，创建六模块用户点控规则。
- 若该用户部分或全部模块已有规则，包括从模块菜单当前模块点控产生的规则，弹窗展示现有规则；保存成功后按既有用户点控设置规则覆盖六个模块。
- 点控方向、生效方式、原子写入和失败回滚规则保持不变。

## 取消点控快捷入口

点击“取消点控”始终打开用户点控取消弹窗，并在打开时根据该用户六个模块的最新规则计算待取消模块：

- 规则来源可以是用户点控设置或任一模块点控。
- 只汇总当前有效规则；已执行、已取消和已覆盖记录不重复处理。
- 存在有效规则时，列出模块、控制方向、生效方式和状态，填写备注后可继续MFA验证。
- 不存在有效规则时，弹窗显示“当前没有可取消的模块”，仍可通过“返回”关闭，但取消备注和“继续MFA验证”不可用。
- 无有效规则时不创建取消日志，不发起MFA验证，也不改变任何模块状态。

## 列表状态

“是否点控中”列继续按六模块当前有效规则计算，仅用于快速识别，不再控制操作入口是否出现。

## 弹窗交互约束

用户点控取消弹窗同时遵守以下要求：

1. 点击遮罩不得关闭弹窗，只能通过弹窗内明确操作关闭。
2. 遮罩固定覆盖整个视口。
3. 弹窗外框不滚动并限制最大高度；内容超出时仅内容区域滚动。
4. 标题和底部操作区始终保留在固定外框内。

## 产品文档同步

更新通用版产品文档，删除“点控”和“取消点控”根据状态互斥展示的规则，改为两个入口始终同时展示，并补充无有效规则时的取消空状态。

## 验收标准

1. 无论用户是否存在有效规则，操作菜单同时显示可点击的“点控”和“取消点控”。
2. 模块独立规则可通过用户列表的“取消点控”用户点控取消。
3. 无有效规则时，点击“取消点控”仍打开弹窗并显示明确空状态。
4. 无有效规则时不能进入MFA验证，也不写入取消日志。
5. 有效规则存在时，既有取消流程保持可用。
6. “是否点控中”列的判断逻辑保持不变。
7. 产品文档与界面行为一致。
8. 自动化测试、生产构建和实际页面交互验证通过。
