# Dialog 打开关闭动画规范设计

## 目标

在现有 Dialog 交互规范中增加统一的打开和关闭动画要求，并同步到个人 Skill 与项目级 `AGENTS.md`。动画必须保持克制、可访问、状态安全，不能削弱现有遮罩、滚动和关闭约束。

## 动画方案

采用“淡入淡出 + 轻微缩放”。

### 打开

- 遮罩：`opacity: 0 → 1`。
- Dialog：`opacity: 0 → 1`。
- Dialog：`transform: scale(0.96) → scale(1)`。
- 时长：`200ms`。
- 缓动：`ease-out`。

### 关闭

- 遮罩：`opacity: 1 → 0`。
- Dialog：`opacity: 1 → 0`。
- Dialog：`transform: scale(1) → scale(0.96)`。
- 时长：`150ms`。
- 缓动：`ease-in`。
- 必须等待关闭动画完成后再卸载 Dialog DOM。

遮罩与 Dialog 分别动画，不能通过动画整个挂载容器破坏全屏覆盖、定位或事件边界。

## 状态与生命周期

- 打开开始时立即建立全屏遮罩、页面滚动锁定和焦点约束。
- 关闭动画完成前保持遮罩、滚动锁定和焦点约束。
- 关闭动画完成后才能恢复页面滚动、将焦点返回原触发元素并卸载 DOM。
- 动画过程中屏蔽重复打开或关闭操作，防止重复状态切换、闪烁、残留遮罩或重复回调。
- 明确关闭、取消、确认和业务操作仍是唯一允许触发关闭的行为；点击遮罩不得触发关闭动画。

## 减少动态效果

当 `prefers-reduced-motion: reduce` 生效时：

- 禁用缩放。
- 淡入淡出时长不超过 `50ms`，也允许直接切换。
- 仍必须完整执行焦点管理、滚动锁定、关闭清理和 DOM 卸载顺序。

## 与现有规则的关系

动画期间及动画结束后始终满足：

1. 点击遮罩不关闭 Dialog。
2. Dialog 外框不滚动，只有内容区域可滚动。
3. 遮罩覆盖整个视口。
4. 动画不得产生临时可点击漏洞、局部遮罩、页面提前滚动或焦点逃逸。

## 同步范围

- 个人 Skill：更新 `references/dialogs.md`，增加第四条强制规范和完成前检查。
- 项目约束：更新 `fex-admin/AGENTS.md`，加入同等动画验收规则。
- 开源文档：更新 Skill 仓库 `README.md` 的规则摘要，不复制完整实现细节。
- `SKILL.md` 触发范围和路由保持不变。

## 验收

- 打开动画为 200ms ease-out，遮罩淡入，Dialog 淡入并从 0.96 缩放到 1。
- 关闭动画为 150ms ease-in，按相反方向播放并完成后卸载。
- 快速连续操作不会重复动画、重复回调或留下遮罩。
- 关闭动画过程中页面不能提前恢复滚动，焦点不能提前返回或逃逸。
- reduced-motion 禁用缩放，淡入淡出不超过 50ms 或直接切换。
- 桌面与移动视口下，动画全过程仍满足三条既有 Dialog 规则。
