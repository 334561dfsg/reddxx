# 会员充值分页演示数据设计

## 目标

为截图中的 `user_1001` 提供足够的充值测试记录，使会员累计充值抽屉实际显示分页控件并可浏览第二页。

## 数据设计

- `user_1001` 固定生成 7 条充值记录。
- 每条记录使用唯一的记录 ID 和流水号，并提供金额、计入等级金额、充值来源及合法时间。
- 时间分布按新到旧设置；仓库仍通过现有排序逻辑返回时间倒序结果。
- 第一页显示前 5 条，第二页显示剩余 2 条。
- 其他会员的充值测试数据保持不变。
- 累计充值、计入等级金额及会员升级进度继续由完整记录集合实时计算，不写死汇总值。

## 测试

先增加失败的仓库测试，断言 `user_1001` 返回 7 条记录、时间倒序、流水号唯一，并断言累计金额等于 7 条记录金额之和。确认测试因当前只有 1 条记录而失败后，再补充最小测试数据并运行仓库测试、充值抽屉组件测试、根项目测试和生产构建。

此次仅变更 mock 数据，不改变 Drawer 分页、接口形状或业务逻辑。真实浏览器中的桌面、窄屏、缩放、触摸、键盘及辅助技术检查，仅在实际执行后报告为已验证。
