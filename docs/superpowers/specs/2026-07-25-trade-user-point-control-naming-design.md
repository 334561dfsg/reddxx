# 交易模块“用户点控”命名命名设计

## 目标

将交割合约、永续合约、现货交易三个模块中的“用户控盘”改名为“用户点控”，与AI量化交易、流动性挖矿、投资组合及产品文档保持一致。

## 修改范围

- 左侧导航菜单名称。
- 页面路由标题。
- 模块用户点控页面默认功能名称。
- 用户点控模块元数据中的操作名称。
- 对应导航和界面自动化测试断言。

## 命名结果

- 交割合约／用户点控
- 永续合约／用户点控
- 现货交易／用户点控

## 不变范围

- 路由地址保持不变。
- 页面布局和交互保持不变。
- 点控状态、Mock数据、日志和业务规则保持不变。
- 历史提交记录不做修改。

## 验收标准

1. 三个交易模块的左侧菜单均显示“用户点控”。
2. 进入页面后的路由标题不再显示“用户控盘”。
3. 页面标题和功能元数据使用“用户点控”。
4. 当前源代码和测试中不存在三个交易模块仍使用“用户控盘”的有效文案。
5. 相关测试和生产构建通过。
