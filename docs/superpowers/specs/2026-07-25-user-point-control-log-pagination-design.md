# 用户点控日志菜单与分页设计

## 目标

- 将用户管理侧边栏中的“用户控制日志”改为“用户点控日志”。
- 为用户点控日志列表增加与其他后台列表一致的前端分页。

## 界面设计

- 页面标题继续使用“用户点控日志”。
- 侧边栏菜单显示“用户点控日志”，路由地址保持 `/admin/users/control-log` 不变。
- 日志表格底部复用 `AdminListPaginationBar`。
- 默认每页显示 10 条，允许切换为 5、10、20、50 条。
- 分页条展示总条数、当前页、总页数以及上一页和下一页按钮。
- 没有符合条件的日志时保留空状态，不显示分页条。

## 交互规则

1. 先完成现有筛选和时间倒序排序，再对结果分页。
2. UID、模块、规则来源、操作类型、开始日期或结束日期发生变化时，当前页重置为第 1 页。
3. 修改每页条数时，当前页重置为第 1 页。
4. 清除筛选后回到第 1 页。
5. 当筛选结果减少、当前页超过总页数时，将当前页收敛到最后一个有效页。

## 实现边界

- 仅修改前端 Demo，不增加服务端接口。
- 不改变日志合并、筛选、排序及字段展示规则。
- 复用现有分页组件，不新建另一套分页样式。

## 验证

- 自动化测试覆盖菜单文案、分页后的表格数据源、分页组件绑定和筛选重置规则。
- 运行全量测试与生产构建。
- 在浏览器中确认分页条显示、切换页码和筛选后回到第一页。
