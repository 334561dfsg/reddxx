# 会员累计充值抽屉布局优化设计

## 目标

优化会员累计充值抽屉的信息密度和滚动关系：累计充值与升级进度在常规宽度下并排展示，记录分页始终固定可见，滚动仅作用于充值记录列表。

## 布局

- 抽屉最大宽度从约 576px 增加到约 672px，同时保持 `width: 100%`，不得超出可用视口。
- 标题区固定在抽屉顶部。
- 概览区在可用宽度足够时使用双列布局：累计充值约 220px，升级进度占剩余宽度。
- 当窄视口、字体放大或 200% 缩放使双列无法保持可读时，概览区自动改为上下排列，不产生关键流程的双向滚动。
- 充值记录标题和完整记录总数固定在列表上方。
- 记录卡片列表是抽屉内唯一的纵向滚动区域。
- 分页位于列表下方的固定底部区域，始终显示；只有一页或空记录时也显示总数和页码摘要，翻页按钮按边界禁用。
- 翻页后把记录列表滚动位置复位到顶部。
- 底部分页处理 `safe-area-inset-bottom`，横向边缘继续处理安全区域。

## 状态与行为

- 继续沿用每页 5 条、完整记录总数、页码、上一页和下一页。
- 切换用户或刷新 summary 时继续回到第 1 页，并同步将列表滚动到顶部。
- 不改变充值金额、升级进度、记录排序、空状态、抽屉关闭、动画、焦点、背景隔离和页面滚动锁语义。
- 抽屉外框保持 `overflow: hidden`，不得由遮罩、拖拽或滑动关闭。

## 实现边界

修改 `UserRechargeSummaryDrawer.vue` 的内部布局和分页集成。若共享 `CompactPagination` 当前仅在多页时渲染导航按钮，则通过向该组件增加向后兼容的显式配置来支持“始终显示导航”，默认行为保持不变，避免影响其他页面。

## 测试与验证

测试优先覆盖：672px 最大宽度、约 220px/剩余空间概览布局、窄屏回流、唯一列表滚动区、固定且始终显示的分页、单页禁用按钮、翻页滚动归顶、用户/summary 变化重置页面和滚动位置，以及原有 Drawer 生命周期回归。
