# 用户控盘弹窗紧凑化设计

## 目标

只调整用户控盘相关弹窗的视觉密度，让后台操作时更少滚动、更容易快速确认，不改变列表页、模块页、日志页及任何业务规则。

## 调整范围

- 用户点控设置弹窗。
- 单模块用户控制设置弹窗（复用同一组件）。
- 用户管理中的用户点控取消控制弹窗。
- 模块页面中的单模块取消控制弹窗。

详情抽屉、页面主体和表格不在本次范围内。

## 布局方案

采用“适度紧凑”密度：

- 设置弹窗最大宽度由宽版收窄一级，仍保证长提示自然换行。
- 标题区、正文区和底部按钮区的纵向内边距缩小约 20%–25%。
- 正文分组间距、选项卡间距和卡片内边距一致缩小。
- 控制方向与生效方式仍保持双列选择，不改字段、顺序或点击区域语义。
- 交易类效果与理财类效果改为同一行的紧凑摘要；窄屏仍可自动换行。
- 影响模块标签、备注框、提示和错误文案全部保留，仅压缩留白。
- 取消弹窗同步压缩标题、正文、模块清单、备注框和底部按钮区。

## 保持不变

- 六模块覆盖和原子失败提示必须完整可见。
- 用户名、UID、邮箱、当前规则、控制方向、生效方式、影响模块及备注字段全部保留。
- 单模块/全局作用域、一次性/永久、盈利/亏损和高/低收益映射不变。
- 表单校验、按钮禁用、键盘交互、关闭方式及提交/取消行为不变。
- 不新增接口、服务端、数据库或真实交易逻辑。

## 响应式与可用性

- 桌面端优先减少纵向高度，目标是在常见后台窗口中无需或仅需少量滚动。
- 小屏继续使用全宽弹窗和现有滚动容器，双列内容按已有断点变为单列。
- 按钮和单选项保留足够点击面积，正文最小字号不低于现有 `text-xs`。

## 验收

- 设置弹窗与两类取消弹窗的结构和信息完整。
- 弹窗间距、卡片和选项高度明显低于当前版本，但不出现文字遮挡或溢出。
- 现有用户控制测试全部通过，生产构建成功。
- 样式修改不影响弹窗外页面。
