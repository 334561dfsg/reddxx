# 用户点控 Dialog 完整交互规范改造设计

## 目标

按照项目最新 Dialog 规范，重新处理用户点控链路中的设置、取消、详情和 MFA 弹层。在不改变点控业务规则的前提下，一致的动画、焦点、键盘、背景隔离、异步状态、响应式布局和资源清理，并保留既有的全视口遮罩与正文独立滚动行为。

## 范围

本次覆盖以下 5 类弹层：

1. 用户管理用户点控和六个模块点控共用的 `UserControlModal.vue`。
2. 用户列表中的用户点控取消 Dialog（`UserListPage.vue`）。
3. 六个模块共用页面中的模块取消 Dialog（`ModuleUserControlPage.vue`）。
4. 用户点控详情抽屉 `UserControlDetailDrawer.vue`。
5. 点控设置和用户点控取消流程调用的共享 MFA Dialog `MfaVerificationModal.vue`。

不扩展处理后台其他业务 Dialog，不修改点控或 MFA 的数据结构、路由和业务计算。

## 实现方案

新增轻量的 Dialog 生命周期 composable，集中管理五类弹层共享的行为；各组件继续维护自己的布局、文案、字段和业务回调。

composable 的职责仅包括：

- 打开与关闭阶段管理，并在关闭动画结束后通知组件卸载。
- 捕获触发元素、设置初始焦点、限制 Tab 循环和关闭后回焦。
- 仅让最上层 Dialog 响应 Escape 和键盘焦点约束。
- 打开期间锁定页面滚动，并对应用背景及下层 Dialog 设置 `inert`。
- 组件关闭、路由变化或卸载时清理滚动锁、`inert`、事件监听和动画状态。

不新增承载业务 UI 的通用 Dialog 组件，避免扩大现有模板迁移范围。

## 结构与层级

- 所有弹层使用 `Teleport to="body"`，遮罩采用 `position: fixed; inset: 0` 覆盖完整视口。
- 使用共享层级注册顺序确定顶层弹层，禁止组件自行叠加任意层级规则。
- 遮罩不绑定关闭事件；Dialog 只能通过内部关闭、取消、返回、确认或允许的 Escape 操作关闭。
- 页面背景和所有下层 Dialog 在顶层弹层存在时保持不可交互。
- 居中 Dialog 外框使用纵向 flex、动态视口最大高度和 `overflow-hidden`；抽屉使用全高固定外框。
- 标题和底部操作区固定在外框内，只有正文区域使用 `min-h-0 flex-1 overflow-y-auto`。
- 动态视口高度同时提供 `vh` 回退，确保不支持 `dvh` 的浏览器仍能约束高度。

## 动画与挂载

- 打开时遮罩淡入，Dialog 淡入并由 `scale(0.96)` 过渡到 `scale(1)`，持续 `200ms ease-out`。
- 关闭时反向播放，持续 `150ms ease-in`；结束后才卸载 DOM。
- 抽屉沿用右侧进入方向，但同时满足规定的淡入和缩放；遮罩独立淡入淡出。
- 动画进行中忽略重复打开和关闭请求，关闭结束前继续保留遮罩、背景隔离、焦点约束和滚动锁。
- `prefers-reduced-motion: reduce` 时取消缩放，淡入淡出缩短到不超过 `50ms`。

## 焦点、键盘与语义

- 每个 Dialog 使用可见、唯一的标题 ID 和 `aria-labelledby`，保留 `role="dialog"` 与 `aria-modal="true"`；不把复杂正文写入 `aria-describedby`。
- 点控设置打开后聚焦第一个控制方向选项。
- 用户点控取消和模块取消属于不可逆操作，打开后聚焦破坏性最低的“返回”按钮。
- 详情抽屉内容较长，打开后聚焦标题静态元素。
- MFA 打开后聚焦验证码输入框。
- 顶层 Dialog 内的 `Tab` 和 `Shift + Tab` 循环覆盖所有当前可见且可用的可聚焦元素。
- Escape 默认只关闭最上层 Dialog；MFA 验证中禁止 Escape、取消和关闭。
- 关闭动画完成后焦点返回触发按钮；触发按钮已不存在时，回到仍存在的合理父流程控件。
- 所有关闭、取消、返回和确认操作保持可见、可聚焦且具有可访问名称。

## 异步与错误

- MFA loading 期间禁止重复验证、取消、关闭和回调执行，并通过 `aria-busy` 表达状态。
- loading 按钮继续显示“验证并继续”的可访问名称，视觉文案可显示“验证中”。
- 本地验证码校验失败时保持 Dialog 打开，显示文本错误摘要并将焦点移到错误位置。
- 父流程异步失败时不得自动关闭 MFA；错误信息需通过组件属性或事件结果保留在 Dialog 内并可被辅助技术读取。
- 每次重新打开清空旧验证码、本地错误、关闭阶段和重复提交锁。

## 各弹层改造

### 点控设置

保留现有紧凑表单和业务校验，接入共享生命周期、标题关联、初始焦点、焦点陷阱、Escape、回焦、动效与背景隔离。标题和底部固定，表单正文独立滚动。

### 用户点控取消

保留模块列表、空状态、备注和 MFA 衔接。打开时聚焦“返回”，确认后关闭当前层并打开 MFA；MFA 关闭后焦点回到该流程中合理位置。无有效规则时仍保留明确的内部退出操作。

### 模块取消

保留只影响当前模块的业务规则。打开时聚焦“返回”，备注区独立滚动，Escape 只关闭当前顶层 Dialog。

### 点控详情抽屉

保留右侧全高布局和详情内容。标题可编程聚焦，正文独立滚动，遮罩不可关闭，Escape 和关闭按钮退出后回焦到详情触发按钮。

### MFA

保留验证码规则及验证事件。增加可访问标题关联、输入初始焦点、顶层 Escape 规则、loading 防重、错误聚焦、关闭动画延迟卸载和 reduced-motion 行为。

## 测试与验证

### 自动化测试

- 为 composable 增加可执行行为测试，覆盖阶段变更、顶层判定、Escape、Tab 循环、回焦、滚动锁、`inert` 和清理。
- 更新点控 UI 测试，覆盖五类弹层的标题语义、固定外框、独立正文滚动、无遮罩关闭、动画类、reduced-motion、异步防重和错误呈现契约。
- 保留现有点控状态、表单、取消、MFA 和日志测试，防止业务回归。
- 执行完整 `npm test` 和生产构建。

### 浏览器交互验证

在用户列表及任一模块点控页实际验证：

1. 五类弹层的打开、内部关闭、遮罩点击不关闭及关闭动画后卸载。
2. 初始焦点、Tab/Shift+Tab 循环、Escape 顶层关闭和关闭后回焦。
3. 页面与下层弹层的指针、键盘和辅助技术隔离。
4. 长内容下仅正文滚动，标题和操作区保持可达。
5. 快速连续打开/关闭、MFA 重复提交、错误保留和 loading 禁止中断。
6. 桌面、移动、低高度、浏览器缩放和虚拟键盘视口。
7. 正常动画和 `prefers-reduced-motion`。
8. 多次打开、路由变化和组件卸载后无残留遮罩、滚动锁、`inert` 或监听器。

任何未实际执行的交互或视口检查必须在交付说明中标为未验证，并列出所需检查。

## 不变范围

- 不修改点控方向、生效方式、状态、覆盖优先级和六模块原子写入规则。
- 不修改取消规则、操作日志、执行日志和页面路由。
- 不修改 MFA 验证码业务规则或成功回调含义。
- 不重构后台其他 Dialog，也不创建承载业务内容的通用 Dialog 组件。

## 验收标准

1. 五类点控弹层满足项目 Dialog 规范的全部 27 条强制要求。
2. 遮罩始终覆盖视口且点击不会关闭；外框不滚动，仅正文区域滚动。
3. 打开、关闭及 reduced-motion 动画时序正确，关闭完成前保持模态隔离。
4. 初始焦点、焦点陷阱、顶层 Escape 和关闭后回焦正确。
5. 语义名称、可见操作、背景 `inert` 和多层隔离完整。
6. MFA 异步期间不存在重复提交、关闭或回调，错误保持可读。
7. 小视口、低高度、缩放和虚拟键盘下控件仍可访问。
8. 关闭、路由变化、卸载和重开后不存在残留状态或资源。
9. 点控与 MFA 业务逻辑不变，自动化测试和生产构建通过。
