# 用户点控Dialog交互规范统一设计

## 目标

按照项目最新Dialog交互规范，统一用户点控流程中全部弹窗和抽屉的遮罩、关闭方式、高度限制和滚动区域，在不改变业务功能的前提下消除误关闭、整框滚动和遮罩覆盖不完整的问题。

## 处理范围

本次覆盖以下5类界面：

1. 用户管理统一点控和模块点控共用的设置弹窗 `UserControlModal.vue`。
2. 用户管理中的统一取消弹窗 `UserListPage.vue`。
3. 六个模块用户点控页面中的模块取消弹窗 `ModuleUserControlPage.vue`。
4. 用户点控详情抽屉 `UserControlDetailDrawer.vue`。
5. 用户点控流程调用的共享MFA验证弹窗 `MfaVerificationModal.vue`。

不扩展处理后台其他业务模块的Dialog。

## 统一结构规则

### 遮罩层

- 所有弹窗和抽屉通过 `Teleport to="body"` 挂载到应用根层级。
- 遮罩采用 `position: fixed` 和 `inset: 0`，完整覆盖浏览器视口。
- 遮罩层本身不承担内容滚动。
- 点击遮罩不得关闭Dialog；删除 `@mousedown.self`、`@click.self` 或等效关闭逻辑。
- Dialog只允许通过关闭、取消、返回、确认等弹窗内部明确操作关闭。

### Dialog外框

- 居中弹窗外框使用纵向flex布局。
- 外框限制最大高度，不超过当前视口可用区域。
- 外框必须设置 `overflow-hidden`，不允许出现外框滚动条。
- 标题区域和底部操作区域不参与滚动，并始终位于外框内。

### 内容区域

- 中间内容区使用 `min-h-0 flex-1 overflow-y-auto`。
- 内容超过可用高度时，只滚动中间内容区。
- 内容较少时不强制出现滚动条。
- 长表单、长规则列表和错误提示必须可以通过内容区滚动完整访问。

### 抽屉

- 详情抽屉继续使用全高右侧布局。
- 抽屉外框保持 `overflow-hidden`。
- 头部固定，只有详情内容区域滚动。
- 点击抽屉外遮罩不关闭，只能通过抽屉内关闭按钮退出。

## 各组件设计

### 1. 点控设置弹窗

- 保留现有紧凑表单和桌面布局。
- 移除遮罩层 `overflow-auto` 和遮罩点击关闭。
- 弹窗外框增加最大高度、纵向flex和 `overflow-hidden`。
- 将表单主体设为唯一纵向滚动区域。
- 标题和底部“取消／确认设置”固定在外框内。

### 2. 用户管理统一取消弹窗

- 保留当前无规则空状态、备注禁用和MFA保护逻辑。
- 保留当前固定遮罩、不可遮罩关闭、外框不滚动和内容区滚动结构。
- 补充与其他用户点控Dialog一致的自动化契约测试。

### 3. 模块取消弹窗

- 移除遮罩点击关闭。
- 外框增加最大高度、纵向flex和 `overflow-hidden`。
- 模块规则摘要和取消备注所在主体成为唯一滚动区域。
- 底部操作按钮固定在外框内。

### 4. 用户点控详情抽屉

- 保留 `Teleport`、固定全屏遮罩、全高外框和独立内容滚动。
- 保留遮罩不可关闭行为。
- 补充统一结构测试，防止后续回归。

### 5. MFA验证弹窗

- 保留全屏固定遮罩和现有验证逻辑。
- 从遮罩层移除 `overflow-y-auto`。
- MFA外框限制最大高度并保持 `overflow-hidden`。
- 验证说明、验证码输入和错误信息进入独立内容滚动区。
- 底部取消和验证按钮固定在外框内。

## 不变范围

- 不修改点控方向、生效方式、状态和覆盖优先级。
- 不修改六模块统一写入、失败回滚、取消和日志规则。
- 不修改MFA校验流程、验证码规则和成功回调。
- 不修改表单字段、业务提示、按钮名称和路由。
- 不新增通用Dialog基础组件。

## 测试设计

### 自动化结构测试

对5类组件统一验证：

1. 使用 `Teleport to="body"`。
2. 遮罩存在 `fixed inset-0`。
3. 不存在遮罩点击关闭事件。
4. 外框存在最大高度或全高约束及 `overflow-hidden`。
5. 中间内容区存在 `min-h-0 flex-1 overflow-y-auto`，抽屉按其全高结构验证。
6. 标题和底部操作区不位于滚动容器内部。

### 实际交互验证

在用户管理和任一模块用户点控页面验证：

- 点击遮罩后弹窗保持打开。
- 点击取消、返回或关闭按钮可以正常关闭。
- 使用长内容时外框无滚动条，只有内容区滚动。
- 遮罩尺寸等于视口尺寸。
- 桌面视口下布局不溢出。
- 如当前浏览器支持调整视口，再验证窄视口；无法调整时必须明确标注未完成真实窄屏验证。

## 验收标准

1. 5类Dialog/抽屉全部符合项目Dialog强制规则。
2. 用户无法通过点击遮罩意外关闭点控表单、取消确认、详情或MFA弹窗。
3. 任何弹窗外框均不出现滚动条。
4. 内容溢出时只有中间内容区域可以滚动。
5. 遮罩始终覆盖整个视口。
6. 弹窗内明确关闭和业务操作保持可用。
7. 用户点控和MFA业务逻辑没有变化。
8. 自动化测试、生产构建和可执行的实际交互验证通过。
