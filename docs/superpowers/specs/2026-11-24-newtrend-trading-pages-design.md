# Newtrend trading pages

用户选定：按 GMXX 分页面和布局，保留当前 UI 风格。仅修改 newtrend；交易v2 不动，使用现有根服务和无语言 URL。

Chrome 参考：standardContract 为图表、盘口、右侧表单，四类合约记录；contractTransaction 为对应期权/交割表单和当前/历史订单；spotGoods 为左盘口、中间图表及下方双列买卖、右行情列表、当前/历史现货委托。不复制账户数据、配色、技术指标或资金快捷行。

方案：采用三个明确路由及页面组件，复用行情、图表、盘口、下单及记录基础能力。排除只改变路由而继续混合记录的方案；排除复制三套业务逻辑以免确认和费用行为漂移。

保留已有 USDT、收藏持久化、六语言、确认与错误处理；不恢复技术指标和记录筛选条。各产品记录互相隔离，期权订单按 settled 分为当前/历史。切换页面保留每种产品草稿、行情搜索/分类/排序、周期、记录选择与分页；刷新只保证已有持久化收藏和语言。

响应式：同一实例通过 CSS 网格重排，窄屏纵向排布；所有记录、行情搜索和下单操作可访问。固定表单动作、正文滚动、safe-area、低高度视窗和焦点保留。
