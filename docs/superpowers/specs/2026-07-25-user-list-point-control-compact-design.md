# 用户列表点控信息精简设计

## 目标

精简用户列表中的点控信息和操作入口，减少横向列宽与操作按钮数量。

## 列表调整

- 删除“统一控制”“生效方式”“模块状态”“更新时间”四列。
- 新增唯一状态列“是否点控中”。
- 用户任一模块存在当前有效或处理中的规则时显示绿色“是”，否则显示灰色“否”。
- 保留点击整行打开用户资料的现有交互。

## 操作下拉菜单

- 操作列只显示一个“操作”下拉触发按钮。
- 下拉菜单仅包含“点控”“取消点控”“点控日志”。
- “点控”打开现有统一点控弹窗，同时承担首次设置和修改规则。
- 没有当前有效规则时，“取消点控”置灰且不可点击。
- “点控日志”跳转到当前用户的用户点控日志页面。
- 删除原“用户资料”和“控制详情”操作入口；用户资料仍可通过点击整行打开。

## 范围

本次只调整前端原型界面及对应测试，不修改 Mock 数据结构、点控弹窗、取消流程或日志路由。

## 验收

- 用户列表只剩一个点控状态列。
- 操作列只呈现一个下拉触发按钮。
- 下拉菜单只有三个指定入口，且保留原有设置、取消和日志行为。
