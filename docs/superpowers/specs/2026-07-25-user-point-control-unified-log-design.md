# 用户点控合并日志设计

## 目标

将现有“用户控制日志”页面调整为简洁的单列表日志页，移除 Demo 提示和操作/执行双页签。

## 界面

- 页面标题改为“用户点控日志”。
- 删除“Demo 演示页 / 所有模拟只在当前浏览器内存中生效”提示卡。
- 删除“操作日志 / 执行日志”页签。
- 保留现有筛选区，筛选条件作用于合并日志列表。
- 使用一张表按时间倒序展示设置、取消和执行记录。

## 字段

合并列表展示：时间、操作人、UID、模块、日志类型、规则来源、生效方式、业务/批次号、变更前、变更后、状态、备注。操作记录没有业务单号或状态时显示“—”；执行记录没有操作备注时显示“—”。

## 数据范围

本次只调整前端 Demo 页面。合并列表由现有 `operationLogs` 与 `executionLogs` 在页面内映射合并，不修改 Mock 状态结构或服务器接口。

## 验收

- 页面不再出现 Demo 提示卡和日志页签。
- 页面只出现一张日志表。
- 设置、取消、执行三类记录均可显示并受现有筛选条件控制。
- 页面标题及相关测试使用“用户点控日志”。
