# 操作反馈统一为 toast

用户要求全站成功、失败和校验提示使用 toast，不再嵌入页面。范围包括根后台、旧前台、代理系统、NewQuantCapital 和交易 V2。

## 实现

- 现有命令式 `message.success/error` 保留；已有响应式错误/结果状态通过共享 `src/shared/feedback/FeedbackToast.vue` 对接 Ant Design Vue message。原有错误块不再占据页面布局。
- 适配器保留无障碍描述 ID 与校验关联；错误摘要 ref 将焦点送到可编辑控件，而不是隐藏描述。重试、充值和认证等恢复入口保留。
- 原生 dialog 内的 toast 在其 top layer 内显示，普通页面使用公共消息层。保留 ConfigProvider 主题、单次展示、卸载清理；同一作用域同时发生的字段错误去重合并。
- 已处理借贷、理财、C2C、账户认证/密码、充值提现/划转、交易表单与记录、后台用户及代理操作、MFA、报表、产品配置等可识别的瞬时反馈入口。
- 业务状态、历史记录里的失败原因、空态、加载态、字段说明以及明确的拒绝/放弃确认内容继续作为业务内容展示。
- 根 AGENTS.md、公共站与交易 V2 约束已记录规则，根 `npm run check:feedback` 通过模板 AST 扫描防止常见内嵌反馈样式回归。该检查不能替代人工审查自定义命名或新的反馈形式。

## 验证

- 静态扫描 351 个 Vue 页面/组件，通过；根构建通过；diff check 通过。
- 根全量测试 788 项：783 通过，5 项既有失败（MFA lifecycle 焦点次数 1 项、UserOnchainWalletDrawer 测试给只读 navigator 赋值 4 项）。本次调整了旧测试中要求内嵌错误块的呈现断言，保留校验、状态和层级断言；增加 toast 合并/去重、适配器描述及规范检查测试。
- 公共站 59 项通过，六语言检查通过（每种 4071 keys）。
- 浏览器实测登录空表单反馈、理财原生 dialog 金额校验 toast 可见及关闭清理、后台风控设置非法值保存反馈和重置恢复；未执行真实金融动作。
- 未逐页执行全部业务成功/失败分支，交易 V2 本次仅静态/构建/测试验证。移动端、200% 缩放、虚拟键盘、横屏、高对比、减弱动画及完整键盘/屏幕阅读器流程未实测，需在相应设备继续检查。
