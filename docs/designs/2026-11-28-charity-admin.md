## 数据

共享模块 `src/shared/charity/{domain,seed,service,client}.js`，页面内静态数据（刷新重置，不做浏览器持久化），不与前台同步，前台未接入。

- **项目**：6 种语言的名称与简介（English 必填且排第一，其他语言留空时逐字段回退 English；完全为空的语言版本保存时丢弃）、封面图片（上传 JPG/PNG/WebP ≤2MB，以 data URL 存在页面内存、刷新即失效、未接真实存储；也可填写图片地址）、目标金额、初始已募金额（Mock 配置）、受助人数、单笔最低/最高捐赠、排序权重（数值越大越靠前）。
- **已募金额** = 初始已募 + 该项目已完成捐赠合计；进度 = 已募 / 目标，显示封顶 100%（种子里有超额完成的项目）。
- **状态**：新项目默认未上架；保存配置不改变上下架状态；上下架只在列表操作列，按 `expectedStatus` 防并发、防重复，记录前后快照。
- **保存**：按 `version` 拒绝过期编辑；日志列出变更字段并保存前后快照；不需要填写操作原因。
- **捐赠记录**：前台捐赠即时完成，因此后台只读，没有审核（用户决定）。记录保存捐赠时的项目名称，列表显示项目当前名称。
- **频道统计**：总募集 = 历史募集基数 + 全部项目（含已下架）已募合计；受助人数 = 历史受助人数基数 + 全部项目受助人数合计。基数默认 0，保存按版本校验并记录前后值。
- **种子**：8 个前台项目，6 种语言名称取自 `newtrend-website/src/locales/*/data.json`；16 条演示捐赠；每个项目的初始已募 = 前台快照已募 − 种子捐赠，因此已募、总募集、受助人数与前台完全一致。演示用户与审核/操作身份均标明「模拟」。
