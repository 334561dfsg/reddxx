# 新版金融理财管理台

## 范围

独立 `/admin/earn/*` 模块管理 NewQuantCapital「金融 → 理财」，不属于 AI 策略或量化基金。提供产品、申购订单、持仓、赎回、收益、操作日志六个页面。

当前为独立内存 mock，路由切换保留、整页刷新恢复。没有后端请求、资金账本操作或与公共前台的数据联动。真实鉴权、事务、资金冻结与释放、计息任务、审核人身份需后续后端接入。

## 业务规则

- 申购待审核时不创建持仓、不计息、不开始期限；审核通过才创建持仓、设置起息与到期时间并冻结条款。拒绝不产生持仓或收益。校验产品状态、额度并防止重复处理。
- 产品支持活期／定期，新增保存为草稿，已有产品币种与期限不可修改。日利率配置上下限供未来服务端随机计息；预计年化收益率独立展示，新持仓不伪造已执行利率。
- 仅定期显示提前赎回开关，开启后设置手续费率与基数（本金或本金＋本次待结算收益）。按持仓冻结条款计算；已发收益不重复计入，不按活期利率重算收益。
- 活期和定期均可配置赎回是否需要人工审核，默认开启。新申请记录该设置，人工审核通过才结算，拒绝恢复持仓；自动结算记录系统身份。切换产品设置不处理既有待审核申请。
- 初始募集进度输入百分比，按总额度自动换算初始金额；修改额度保留比例。展示已申购量＝初始金额＋实际审核通过金额，剩余额度与申购容量校验使用同一口径。实际金额不能通过产品编辑修改。
- 所有操作均无需填写操作原因，自动记录动作和变更前后。订单和赎回列表展示审核人，模拟身份明确标记；待审核操作为“审核”，其他为“详情”。
- 持仓“收益”操作打开右侧抽屉，按 holdingId 严格关联记录，展示金额、状态、计息与发放时间。结算后消耗对应待发收益并新增关联持仓的发放记录。

## 页面与交互

采用 Ant Design Vue 与 Ant Design Pro 查询表格布局：独立查询卡片和表格卡片，搜索条件分开输入，显式查询／重置，金额右对齐，固定右侧操作列。移除顶部标题、统计卡和重复说明横幅。列表募集进度仅显示数字，不使用进度条。用户 UID 可打开现有用户详情抽屉。

产品新增／编辑为独立页面，按基本信息、收益与赎回、申购额度、展示与说明分组，不使用 Tab 或紧凑弹窗。返回置于右侧，底部保存／取消操作栏吸附；浮动导航避让操作栏。币种支持搜索，表单离开保留未保存确认。

统一继承 Ant Design 字体与组件主题，默认 14px 字号、32px 控件。宽屏使用 Table，窄屏 List＋Descriptions 保留字段与操作。弹窗与收益抽屉接入共享生命周期，禁用背景关闭，保留固定头尾、内容滚动、焦点与层级管理。
