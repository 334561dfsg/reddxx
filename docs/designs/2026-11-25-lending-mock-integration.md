# 借贷后台与新版前台 Mock 联动

用户要求完善现有借贷后台并接入新版借贷；随后明确不要本地持久化，仅做 Mock。

## 边界与运行

- 2026-11-27 起改为静态数据：Mock 服务在页面内存中运行（`src/shared/lending/client.js` 直接调用 `service.js`），不再有 `/api/mock/lending` 接口，静态发布也可用；刷新即重置，后台与前台不再共享实时状态。
- 不使用 localStorage、sessionStorage、文件或数据库保存借贷业务数据。浏览器刷新保留服务内存，重启开发/预览服务重置。
- 根 `npm run dev` 或 `npm run build && npm run preview` 支持前后台跨标签页联动；界面每 3 秒刷新一次，离开页面停止订阅。
- 纯静态托管不包含 Mock 接口，必须另行提供同契约服务；接口缺失时显示错误并可重试，不暗中切换浏览器本地数据。
- 身份、余额、价格、授信均为模拟；不是登录鉴权、真实行情、资金账本或真实放款服务。前台使用 USR-DEMO，后台标注“管理员（模拟）”。其他资产页不共用此借贷 Mock 钱包。
- 沿用旧产品 Mock 数据；旧版 `/front` 演示借贷保持原状，本次集成针对 `/NewQuantCapital/earn/loan` 与 `/earn/loan/my`。

## 状态和规则

- 申请：校验上架状态、金额、整日期限、总/币种授信、资金容量、质押余额。预留额度并锁定质押，待审债务为 0，无起息和到期时间。
- 审核：审批时再次校验产品、额度和资金。批准后放款到 Mock 钱包，开始完整期限，保留申请快照的年化、逾期费率和质押条款。
- 拒绝/用户取消：保留订单，释放质押和额度，不生成利息。终态不允许重复审核。
- 计息：固定 APR / 365，按完整日对剩余本金累计，读取接口或操作时按日补算；前台日利率由同一 APR 推导。非后台定时任务。
- 还款：扣可用借出币种余额，先逾期利息、再正常利息、再本金；本金归还产品资金池，全部结清释放质押。已还部分不再计息。
- 质押处置：只在冻结的处置阈值触发、允许处置且仍锁定时执行。按 Mock 价格结算，退回剩余质押；不足部分记录 shortfall，不伪造足额回款。
- 每笔操作先在独立草稿验证，成功整体替换；请求 ID、状态校验阻止重复处理。产品旧快照保存冲突会失败，防止覆盖期间的放款余额。
- 现有授信评分卡保存后将折算额度提交 Mock 服务，同时保存评分卡快照，重新打开可恢复。降低额度不撤回已有放款，但阻止新的超额审批。

## 页面和接口

- 后台沿用产品、订单、还款、日志路由，使用 Ant Design Vue 查询卡、表格和窄屏 List/Descriptions。
- 产品支持创建、编辑、上下架（编辑状态）、排序、资金容量、质押开关与币种、期限、年化、逾期日费率、风险阈值。
- 订单查看审核人、冻结条款、起息/到期、质押风险、关联还款、资金流水；UID 复用用户抽屉。
- 模态复用现有共享生命周期适配器，保留遮罩不关闭、固定头尾、未保存确认及焦点恢复。
- 新前台使用产品目录、借款表单、确认区、我的订单过滤分页、取消申请、部分/全额还款、关联还款记录。
- GET 返回统一快照；POST `{action,args}`，动作包含 apply/approve/reject/cancel/repay/liquidate/saveProduct/savePolicy。错误以 `{error:code}` 返回。
