# Ant Design Vue 首批迁移

## 范围

沿用 Vue 3，接入 Ant Design Vue 4.2.6。首批为管理台外框、用户列表主页面与用户充值报表；其余业务页、通知/账户浮层以及现有业务详情、资金操作等复杂弹窗尚未迁移，不能视为整站迁移完成。

- ConfigProvider 中文语言及主题；Layout/Header、Menu、Sider、窄屏 Drawer（禁止遮罩关闭）。
- 用户列表采用 Table、Select、Input、Button、Pagination、Card、Spin，保留所有行操作与原业务处理函数。
- 充值报表采用 Form、Select、DatePicker、Input、Button、Table、Pagination、Popover、Checkbox、Tag，保留逐笔查询与全字段 CSV 导出。
- 区分原型手写 ant-* 样式与真实组件，避免选择器双边框等冲突。仅注册首批需要的组件。
- 现有抽屉协调测试使用 Table bodyCell 和 Button 的公开接口替身，继续验证业务抽屉和焦点返回；源码测试更新为新组件结构。
