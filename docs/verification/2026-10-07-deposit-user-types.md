# 充值报表用户类型

范围：`/admin/users/deposit-report`，只读报表（consoleSurface: report）。在用户 ID 旁显示普通用户、业务员、代理或未知类型，使用与所属业务员相同的 a-select 组件筛选（四个固定选项，无搜索），并保留导出快照中的类型。类型按当前充值用户身份判断，代理优先，其次业务员，普通用户必须有明确 user 角色；所属代理/业务员不改变用户本身类型。缺失资料或不认识的角色不归为普通用户。本功能不构成真实性认证。

筛选默认全部类型，选择后点击查询应用；重置恢复全部类型。筛选和其他条件取交集，查询成功后回到第一页。列表和导出使用同一个成功查询快照。CSV、Excel 增加用户类型，下载任务范围显示已应用类型。

沿用现有页面权限、查询加载/失败/重试、分页及导出任务 owner；未新增租户逻辑、写入、审批、风险操作或审计事件。这些新增能力的 DOM/state/handler/request 数量均为 0。当前仓储仍使用项目的 mock 用户及订单数据，未接真实服务。
