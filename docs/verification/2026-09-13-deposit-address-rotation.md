# 入金列表修改地址

当前流程替换此前用户列表批量地址入口：入金订单每行「详情」旁提供「修改入金地址」，列出启用的公共币种/网络地址。只编辑地址值；确认后打开谷歌身份验证。验证成功，对实际修改项同步保存旧公共地址为该用户专属地址、新地址为公共地址。已有该组合专属地址时会提示替换。未修改组合、其他用户专属配置和历史订单保持不变。

## 实现边界

- 当前为内存 Mock，刷新后重置，不是生产保存。演示验证码为 `123456`，错误验证码拒绝保存。真实 Google TOTP、权限和持久化必须由服务端接入；不可将固定验证码部署成生产鉴权。
- 公共和用户地址使用共享仓库；同步事务在任一写入失败时回滚公共历史、专属数据、回执和审计。正式接口需要对应数据库事务、版本检查及幂等键。
- 按最新要求，地址只做必填检查，不校验地址格式、链上所有权或校验和；保留币种/网络组合检查。原 Mock TRON/BTC 示例更新为符合基本格式的地址。
- 用户详情保留专属地址只读展示。原用户列表操作栏宽度修改保留。
