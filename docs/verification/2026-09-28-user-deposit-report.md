# 用户充值报表验证

用户要求把「用户业绩报表」改为「用户充值报表」，按每一笔充值列出。顶部汇总卡片保持移除。

## 实现

- 菜单、用户列表跳转按钮、页面和 CSV 文件名统一改名；新路由 `/admin/users/deposit-report`，旧路由重定向到新路由。
- 使用入金审核的同一份 `fundOrderApi.listDepositOrders` 演示订单，按充值单号作为行标识，不再按用户合并，也不为无充值用户生成零金额行。
- 列出单号、充值提交时间、用户 ID/昵称、当前代理 ID/邮箱、当前业务员 ID/邮箱、原币金额/币种、订单折合 USDT、充值状态和入账时间。
- 按提交时间的 UTC+8 日期筛选，含首尾日期，按最新提交时间排序；同时列出待确认、已入账、已驳回，用状态明确区分。没有把原币金额当作 USDT，也没有虚构订单未提供的逐笔佣金。
- 查询草稿与已应用快照分离；全部分页取齐后生成报表和 CSV；较早请求和卸载后响应不写回当前页面。
- 继续使用当前归属筛选，不用裂变邀请关系替代代理归属。数据尚未接入真实后端。
