# 用户钱包明细 Ant Design Vue 迁移

- 范围：用户详情资产页的只读币种明细 Dialog；不涉及写入、交易、导出或权限变更。模拟持仓及数据口径保持不变。
- 组件：Ant Design Vue Modal、Table、Statistic、Alert、Empty、Space、Typography、Button，继承现有 ConfigProvider。CSS 仅处理布局、视口、安全区域及项目规定的动画。
- Modal 使用共享 useDialogLifecycle 管理层级、背景 inert、焦点、Escape 和关闭后恢复；库的键盘关闭与自动焦点恢复禁用，防止两个 owner 重复执行。库延迟 Portal 挂载时注册共享层；afterClose 完成共享清理。
- 已验证：生产构建成功；31 项针对性自动化测试通过（数据对账、组件使用契约、共享生命周期及既有 SFC 回归）。旧手写弹窗的模拟渲染测试已替换为组件契约测试；真实 Modal 行为通过浏览器检查，未声称测试宿主可运行 Ant Portal。
- 已在本地浏览器检查：市值/理财明细打开、窄屏呈现、模拟数据标识、标题初始焦点、Tab/Shift+Tab、遮罩点击不关闭、Escape 只关闭顶层、底部关闭、重新打开、关闭后返回原钱包入口；下层抽屉保留。
- 未验证：桌面/平板/横屏/低高度的完整视口矩阵、200% 缩放、系统文字放大、真实触摸、虚拟键盘、四向安全区域设备、减少动态效果、高对比模式、长文本和大量持仓滚动、屏幕阅读器、路由切换期间的实际浏览器清理。需在对应浏览器/设备条件下补测；已有 CSS 和共享生命周期测试不替代这些实机验证。

## 打开闪烁修复

- 源码定位：已安装 Ant Design Vue 的 `getTransitionProps` 在入场首帧使用 `enter-prepare`，后续帧才增加 `enter-active`。原有自定义 CSS 仅在 active 时启动从透明到可见的动画，准备帧缺少透明初始态。
- 修复：Dialog 和 mask 的 enter-prepare / appear-from 明确设为透明，Dialog 初始缩放与入场关键帧一致；减少动态效果时准备帧也禁用缩放。
- 回归：新增两项准备帧样式检查，修复前均失败，修复后通过；合计 23 项数据、动画样式、生命周期测试通过，生产构建通过。
- 本次未执行浏览器逐帧或实机视觉复验；需补测首次打开、连续开关、减少动态效果及不同视口的视觉连续性。样式回归不等同于实机无闪烁结论。

## Ant Table 固定表头

- 改为原生 `Table :scroll="{ y: tableScrollHeight }"`；移除外围滚动容器的滚动行为，由 `.ant-table-body` 独占纵向滚动，表头由 Ant 单独渲染。
- 使用 ResizeObserver 观测表格可用空间与表头高度，按实际剩余高度设置 scroll.y；支持摘要换行、视口调整并在卸载时断开观察。使用 clientHeight/offsetHeight，避免入场 transform 影响测量。
- 数据滚动区支持键盘聚焦并有可访问名称。标题、摘要、表头及底部关闭操作保持在滚动区之外。
- 构建及 6 项现有相关测试通过；实际浏览器表头固定、列对齐、滚动到底、窗口缩放/断点、键盘滚动与重复打开后的 observer 清理仍待浏览器验证，未声称已通过。
