# 账户类型变更日志

新增 permission.account-type.update，标签“账户类型变更”，分类“权限关系”。操作类型筛选通过既有 USER_AUDIT_ACTIONS 自动包含该项。客户与业务员通过编辑资料切换、代理身份通过现有设置入口变更时，在原日志之外追加类型变更日志；仅有效身份发生变化时追加。类型优先级为代理、业务员、客户，记录当前操作者、时间、目标用户、原因、变更前后类型及原业务关联 ID。保留历史日志，不回填或篡改。日志详情桌面与移动端都将 accountType 显示为“账户类型”。新增一条明确标注演示的近期 mock 日志，供默认日期范围筛选查看。

沿用现有内存日志仓储和页面权限、筛选、分页、展开详情、错误处理，不新增写权限、导出、弹层或危险操作。刷新持久化能力未新增，日志仍遵循现有 mock 仓储生命周期。

验证：针对关系变更、日志仓储和日志页面的 28 项测试通过；新增用例覆盖客户转业务员、业务员转代理、代理转业务员、业务员转客户、仅编辑资料不追加及非法类型变更不追加。

未实测：真实浏览器操作筛选、详情展开、键盘/读屏、触摸、手机/平板/横屏/低高度、200% 缩放/系统大字、长文本、虚拟键盘、动态视口、安全区、减少动态效果和高对比度；需检查筛选项可选、日志可查、前后类型可读、详情和操作可达。未验证真实后端日志持久化、权限切换及跨租户边界。
